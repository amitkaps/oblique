Test coverage: @font-face descriptor × use-site CSS

One font, one glyph under test: real Cairo (slnt −11..11), subset to the letters of OBLIQUE, tested on the capital I. Columns (A, B, C…) are what the @font-face declares; rows (1, 2, 3…) are the CSS at the use site, and a cell is its column letter plus its row number. What each cell should do is not decided by hand: an independent JavaScript implementation of CSS Fonts 4 font-style matching (reference/) computes it, and never uses a browser to do so. Where the spec pins the outcome down, the cell is a WPT test; where it leaves latitude (“spec allows…”) the test only forbids what the spec forbids; where it is silent, the cell is only observed. font-synthesis is never set, since it should apply only when a face is missing. Each specimen is live in your browser: pink is a rendering the spec accepts, cyan is the CSS under test; aligned they blend pale, and visible pink is a failure. The circles are recorded results: Chromium and Firefox from wpt run, Safari from a direct safaridriver replay (wpt run proved unreliable on Safari). Candidate for upstreaming; no WPT PR has been opened.
